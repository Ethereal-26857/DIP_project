# chat3
Q:
为什么库函数计算结果有些是N/A？

A:
你看到的 “N/A” 是因为标准库没有提供对应的函数或者你的代码里没有调用库函数来计算那个指标。具体来说：

1️⃣ SSD（平方差和）
SSD      219471320.0000  N/A
手动实现了 ssd()。
标准库没有提供直接计算 SSD 的函数，所以库函数栏显示 N/A。
SSD 很简单，通常只用手动实现就够了。
2️⃣ RIU（Ratio Image Uniformity）
RIU      0.304083        N/A
RIU 是一种比较少见的指标，大部分 Python 库里没有内置函数。
所以库函数没有可用实现，显示 N/A。
只能手动实现。
3️⃣ CC（Pearson Correlation）
CC       0.060434        0.060434
scipy.stats.pearsonr 提供了标准实现，所以可以同时显示手动和库函数结果。
两者数值一致，说明手动实现是正确的。
4️⃣ MI（Mutual Information）
MI       0.945018        0.655801
sklearn.metrics.mutual_info_score 可以计算互信息，因此库函数有值。
不过手动实现和库函数结果不完全一致，可能原因：
手动 MI 使用了掩模和归一化处理
库函数可能只考虑整数离散化或者没有归一化
这也是实验中常见现象。

✅ 总结：

N/A = 库函数没有提供该指标
手动实现 = 可以计算任意自定义指标
